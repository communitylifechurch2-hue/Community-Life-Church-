# Community Life Church Website

A responsive GitHub Pages-ready website for Community Life Church, Mamboleo.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design
- `script.js` — mobile navigation and placeholder buttons
- `images/` — church logo, leadership photo and sanctuary project image

## Before publishing
1. Replace the placeholder media link in `index.html`.
2. Replace the evaluation-form placeholder with the official Google Forms URL.
3. Add worship photos/videos when available.
4. Verify the phone, email, location and Paybill details before going public.

## GitHub Pages
Upload all files to the root of a public GitHub repository.
Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
